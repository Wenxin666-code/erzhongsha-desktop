# 公开版素材说明

公开版于2026-11-21按项目所有者要求移除私人照片、含照片的美术预览和对局截图，以及DIY武将的个人技能、阵亡录音。

## 运行行为

- DIY武将的规则、技能和AI保留；无肖像时使用程序绘制的文字牌面。
- 缺少个人技能或阵亡语音时静默跳过，不复用其他武将的语音。
- 保留不含真人照片的透明边框，以及其余卡牌、UI、效果和声音资源。
- 个人皮肤目录、个人语音目录和美术预览目录加入忽略规则，禁止重新提交。

## 发布范围

公开版使用清理后的独立Git历史；旧提交与原始素材只保留在私有备份中。
旧安装包、构建缓存、原始素材库不纳入本仓库，也不作为公开版附件发布。
后续截图与安装包必须从此公开版生成，不能直接复制私有版产物。

## 许可边界

此处说明个人素材的清理范围，不为其余第三方卡图、UI、背景和音效授予额外许可。
项目尚未选定统一代码许可证；公开可见不等同于允许任意使用或再分发。

## 维护检查

发布前运行完整检查，确认无个人素材回流，并检查打包产物。依赖以uv.lock为准；
保持游戏运行资源的相对路径，不从旧归档自动补齐缺失的个人素材。
