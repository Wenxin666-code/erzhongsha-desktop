武将牌边框资源说明

一、目录用途

diy/frames
    魏、蜀、吴、群的普通武将牌透明整框。

diy/lord_frames
    魏、蜀、吴、群的主公武将牌透明整框。

diy/magatama
    体力勾玉装饰组件。

diy/skill_badges
    技能类型与势力配色标识组件。

diy/common
    通用遮罩与珠联璧合组件。

previews
    公开版不分发美术预览与对局截图，避免包含私人肖像。

runtime
    游戏实际加载的武将专用透明边框。文件名使用稳定 general_id，例如
    dingyichen.png；同一武将的所有皮肤共用该边框。

二、接入原则

1. 武将原画（皮肤）和武将牌边框分层保存，换皮肤时不重复制作边框。
2. 新接入武将默认启用专用边框；旧武将可通过 General.use_portrait_frame
   显式关闭。当前关羽、曹操关闭，保持旧牌面。
3. 游戏绘制时先显示原画，再按 general_id 叠加对应透明边框；不得修改
   原始皮肤文件，也不得在 main.py 按武将名建立特例。
4. 势力字属于边框美术的一部分，不由界面额外叠加。武将姓名也制作在同一
   透明边框内，放在势力字下方的左侧竖槽，并与势力字使用一致的书法风格。
5. 启用专用边框的武将，底部黄色手牌信息只显示“当前手牌数/手牌上限”。
   关闭边框的旧武将继续使用原有牌面布局。
6. previews 中的概念图和色键中间图不作为运行资源；游戏只加载 runtime
   中以 general_id 命名的透明边框。
